    توثيق API للمطورين (اضغط للفتح)
    MethodEndpointالوظيفة
    POST/api/jobsإنشاء مهمة دمج من روابط أو مصادر ملفات
    POST/api/upload?job=&seq=&chunk=رفع أجزاء ملف (ثنائي ≤4MB)
    POST/api/jobs/<id>/processتنفيذ الدمج كاملًا → رابط الفيديو النهائي
    GET/api/jobs/<id>الحالة + التقدم (0–100) + الرابط عند الاكتمال
    GET/api/jobs/<id>/videoبث الناتج بدعم Range — ?download=1 للتحميل
    DELETE/api/jobs/<id>حذف فوري شامل
    GET/api/configالحدود العامة + version
    GET/api/cronحذف المهام المنتهية (Cron يومي)
    أمثلة curl جاهزة للنسخ (الدومين الحقيقي يُملأ تلقائيًا):
    الأخطاء دائمًا بصيغة {"error":"رسالة عربية"} — الرموز: 400 مدخلات تالفة، 404 غير موجود، 409 حالة غير مناسبة، 413 تجاوز الحجم، 405 طريقة خاطئة.
